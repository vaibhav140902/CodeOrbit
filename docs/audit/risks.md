# CodeOrbit Phase 0: Top 10 Platform Risks & Mitigation Matrix

Every risk is assessed across Severity (1–5), Likelihood (1–5), and Blast Radius, yielding a composite Risk Priority Number (RPN = Severity × Likelihood).

---

| Rank | Risk Area | Description | Severity (1–5) | Likelihood (1–5) | RPN | Mitigation Strategy |
| :---: | :--- | :--- | :---: | :---: | :---: | :--- |
| **1** | **API Cost Abuse & Denial-of-Wallet** | Unauthenticated or automated bot traffic hitting Gemini 2.5 Flash (`/api/platform/interview/respond`) or Judge0 code execution endpoints. | 5 | 4 | **20** | Enforce IP + UID token-bucket rate limiting (Redis/Upstash or in-memory LRU), strict quota tiers (1 free mock per account, 5 for Pro), and mandatory Firebase Auth on expensive routes. |
| **2** | **DPDP Act 2023 Non-Compliance & PII Leaks** | Indian candidates uploading unredacted resumes with phone numbers, emails, and addresses without explicit notice, purpose limitation, or easy withdrawal/deletion. | 5 | 3 | **15** | Implement client-side PII scrubbing options, explicit affirmative consent checkboxes conforming to DPDP rules, auto-expiry TTL on resume text (e.g. 30 days), and instantaneous "Delete My Data" endpoints. |
| **3** | **Webhook Forgery & Payment Spoofing** | Attackers faking Razorpay `payment.captured` webhooks to grant lifetime Pro access without paying. | 5 | 3 | **15** | Mandate HMAC-SHA256 signature verification (`crypto.timingSafeEqual`) on `x-razorpay-signature` using the secret key before updating subscription records. Enforce idempotent event processing via unique `payment_id` logs. |
| **4** | **Client-Side Code Tampering & Fake Proof** | Candidates altering JavaScript/browser state to award themselves 100 Readiness Scores or passing tests without running code. | 4 | 3 | **12** | All code evaluations must execute server-side in isolated Judge0 containers against hidden test cases. Proof badges must be signed with a server-side HMAC or verified against database run IDs. |
| **5** | **Fabricated Claims & Legal Exposure** | Unverified statistics ("98.4% ATS Accuracy", "₹7–9 LPA TCS salary", "1,200+ problems", "Aarav Mehta" unlabelled profile) exposing startup to false advertising or trademark complaints. | 4 | 3 | **12** | **Phase 1 Priority:** Audit and remove all unsourced numbers. Bind counts dynamically to actual catalog datasets (`mockProblems.length`, `PREP_QUESTIONS.length`). Distinctly badge demo profiles as "SAMPLE PREVIEW". |
| **6** | **Third-Party Dependency Failure (Judge0 & Gemini)** | Downtime, latency spikes, or quota exhaustion from public Judge0 CE or Google AI Studio endpoints during peak campus placement hours. | 4 | 3 | **12** | Implement automatic fallback to pre-computed deterministic feedback for resumes, graceful degraded UI states with retry queues, and multi-region Judge0 failover. |
| **7** | **macOS iCloud File Eviction & Git Corruption** | Storing repository in `~/Documents` causes macOS iCloud Drive to evict `.git/objects/` to the cloud, triggering `fatal: mmap failed: Operation canceled/timed out` during commits and pushes. | 4 | 4 | **16** | Move active development workspace out of iCloud-synced directories (`~/Documents`) to local non-synced `~/Developer/CodeOrbit` or configure local `.nosync` attributes and run `/usr/bin/brctl download .git`. |
| **8** | **Vercel Output Directory & Edge Build Failures** | Misaligned Turborepo outputs or duplicate `outputDirectory` keys in `vercel.json` breaking deployments with `NEXT_OUTPUT_DIR_MISSING`. | 3 | 3 | **9** | Standardize build scripts to root `npm run build:web`, let Vercel Next.js framework preset auto-detect `.next`, and verify builds locally with `npm run build:web` before pushing. |
| **9** | **Copyright & Plagiarism Claims on DSA Bank** | Reusing proprietary problem descriptions, test suites, or editorials from LeetCode or GeeksforGeeks. | 4 | 2 | **8** | Ensure 100% original problem statements and test suites; maintain problem provenance records (`docs/problem-provenance.md`) with explicit open licensing (MIT / CC-BY-SA). |
| **10** | **Campus GTM & TPO Adoption Churn** | Placement officers failing to mandate student adoption due to complex onboarding or lack of actionable batch insights. | 3 | 3 | **9** | Build one-click CSV batch upload for TPOs, auto-generated NIRF accreditation compliance reports, and instant WhatsApp summary digests for college leadership. |
